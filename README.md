# BGM Player

個人用の音楽再生Webアプリです．ブラウザ上で、区分ごとに整理した楽曲を選択・再生できます．

## 機能

- 区分ごとの楽曲一覧とジャケット画像の表示
- タッチ操作・手動スクロール，およびボタンによる選択・操作
- 近くの項目に吸い付くスクロール（スクロールスナップ）
- MP3ファイルの再生・一時停止
- シークバーによる再生位置の変更
- 繰り返し再生
- プレイヤーを閉じても表示されるミニジャケット（再生画面へのショートカット）
  - ドラッグで移動可能
  - 操作後は画面右側へ吸着し、画面外にはみ出さないように位置を調整

## 対応ファイル

- 音楽：`.mp3`
- ジャケット画像：`.jpg`

## 必要な環境

- Webブラウザ
- Python実行環境（楽曲一覧の生成に使用）

## ファイルの配置

プロジェクトのルートディレクトリに，**`music`** と **`images`** という名前のフォルダを作成してください．フォルダ名は固定です。

両フォルダの直下には，楽曲を分類するための**区分フォルダ**を作成します．区分名は自由ですが，`music` と `images` で同じ名前を使用してください．楽曲・画像をルート直下に直接配置するのではなく，必ず区分フォルダに入れます．

例：

```text
プロジェクトのルート/
├── music/
│   ├── groupA/
│   │   ├── Track01.mp3
│   │   └── Track02.mp3
│   └── groupB/
│       └── Track03.mp3
├── images/
│   ├── groupA/
│   │   ├── groupA_jacket.jpg
│   │   └── Track01_jacket.jpg
│   └── groupB/
│       └── groupB_jacket.jpg
├── make_playlist.py
├── title.txt             # 任意
└── player.json           # スクリプトが生成
```

### ジャケット画像の命名規則

各曲に専用のジャケット画像を設定する場合は，**曲のファイル名から `.mp3` を除いた名前 + `_jacket.jpg`** とします．

例えば `Track01.mp3` に対しては `Track01_jacket.jpg` を同じ区分名の画像フォルダに配置します．

専用画像を用意しない場合は，区分の代表画像を **`区分フォルダ名_jacket.jpg`** として配置してください．その区分の曲に対して代用されます．

## 楽曲一覧の生成

楽曲や画像を配置したら，ルートディレクトリで次のコマンドを実行します．

```bash
python make_playlist.py
```

`make_playlist.py` がフォルダ内のファイルを検出し，楽曲情報を **`player.json`** に出力します．楽曲を追加・変更した場合も，再実行して一覧を更新してください．

各曲には次の属性が設定されます．

| 属性 | 内容 |
| --- | --- |
| `title` | 画面に表示する曲名 |
| `generation` | 区分フォルダの名前 |
| `geneTitle` | 画面に表示する区分名 |
| `filePath` | HTMLから見た音楽ファイルへの相対パス |
| `imagePath` | HTMLから見たジャケット画像への相対パス |

### 表示名の変換（任意）

ルートディレクトリに **`title.txt`** を作成すると，フォルダ名や曲名を画面表示用の名前に置き換えられます．このファイルがなくても問題はありません．

`title.txt` には，1行につき1件，`元の名前=表示名` の形式で記述します．

```text
1th=赤緑
Champion=チャンピオン
```

この場合，区分フォルダ `1th` の表示名（`geneTitle`）は「赤緑」，音楽ファイル `Champion.mp3` の曲名（`title`）は「チャンピオン」になります．元のフォルダ名やファイル名自体は変更しません．

## 操作方法

1. 区分一覧から，スクロールまたはボタンで区分を選択します．
2. 楽曲一覧から再生する曲を選択します．
3. プレイヤー画面で再生・一時停止，シークバーによる再生位置の変更，繰り返し再生などを操作します．
4. 再生中にプレイヤーを閉じるとミニジャケットが表示されます．タップするとプレイヤーに戻れます．ミニジャケットはドラッグして移動できます．

## 注意事項

- `music`，`images` のフォルダ名，および使用する場合の `title.txt` のファイル名は変更しないでください．
- 楽曲と画像は，それぞれ対応する区分フォルダ内に配置してください．
- 対応形式はMP3とJPGのみを想定しています．
- `player.json` は `make_playlist.py` によって生成されます．楽曲構成を変更したら再生成してください．
- 本リポジトリには，個人で用意する楽曲ファイルやジャケット画像を含めません．利用するコンテンツの権利・利用条件を確認してください．
